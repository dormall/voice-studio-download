# 🎙 녹음 스튜디오

목소리를 녹음하면 **노이즈 제거 · 음성 보정이 자동으로** 되고, 캡컷처럼 단축키로 바로 자르고 붙일 수 있는 무료 녹음 프로그램이에요.

## 다운로드

👉 **[녹음 스튜디오 설치 파일 받기 (Windows)](https://github.com/dormall/voice-studio-download/releases/latest/download/VoiceStudio-Setup.exe)**

1. 위 링크로 `VoiceStudio-Setup.exe` 를 받아 실행하세요.
2. "Windows의 PC 보호" 파란 창이 뜨면 **[추가 정보] → [실행]** 을 누르세요. (새 프로그램이라 뜨는 안내예요)
3. 바탕화면의 **녹음 스튜디오** 를 실행하면 끝! 새 버전이 나오면 프로그램 위쪽에 [업데이트] 버튼이 떠요.

## 주요 기능
- 녹음하면 자동으로 노이즈 제거 · 목소리 톤 · 음량 맞춤 (-16 LUFS)
- 녹음 파일을 불러와서 보정만 하기
- 캡컷식 단축키 편집 (분할 Ctrl+B, Q/W 삭제, 자르면 여백 자동 당기기) — 단축키는 마음대로 변경
- 무음 구간 게이지로 쉽게 줄이기
- 중간에 잘못 녹음한 부분만 다시 녹음해서 끼워넣기
- 날짜별 녹음 대시보드, MP3 / WAV 저장

사용 환경: Windows 10 / 11 (64비트)
